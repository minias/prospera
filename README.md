# Prospera World

Prospera World is the interactive WebGL-based company homepage concept for Prospera.

## Current milestone

MVP-01 — Three.js rendering foundation.

### Included

- SvelteKit + Svelte 5 + TypeScript
- Three.js WebGLRenderer
- Scene / Camera / Renderer separation
- Responsive canvas resize
- Animation loop via `renderer.setAnimationLoop`
- Explicit GPU/resource disposal
- Minimal domain state test

### Not included yet

- Player movement
- Raycaster interaction
- AI Core
- Zones
- AI Agent
- GLB assets
- Post-processing

Those are intentionally deferred to later milestones.
